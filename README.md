# 团务助手 · 智慧团建（v0.3.4 发布版）

# 团务助手（v0.3.4）· 安装与使用

一个贴在智慧团建页面右侧的小工具，做六件事：

1. **抓名单**：把团员列表翻页抓全，汇总成一张表，可导出 CSV。
2. **行勾选**：给每行加一个勾选框（系统本身没有），支持 Shift 连选。
3. **记验证码**：你点「生成重置密码验证码」后，弹窗里的码自动记进面板，可一键复制。
4. **评议助手**：把整个支部的评议名单一次读全（29 人），选 → 复核 → 应用，三步走。
5. **团员信息**：扫出当前页的表单字段，只填你要改的，复核后写入，留空的保持原样。
6. **录入预检**：本地校验要导入的 Excel（身份证、年龄、编号年份、手机号），不联网；也可以直接上传表格文件。

**它不做什么**：不点审批、不点提交、不删人、不改任何数据、不联网上传。

---

## 安装（1 分钟）

1. 打开 Chrome 或 Edge，地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」。
4. 选择文件夹：`F:\zhtj\extension`
5. 装好后打开 https://zhtj.youth.cn/zhtj/ ，登录，进入「团员管理 → 团员列表」。

右侧应出现红色标题的「团务助手」面板。没出现就刷新一次页面。

扩展管理页里这个扩展显示的图标、以及面板左上角的小圆徽，都是共青团徽（`icons/`，四档尺寸）。

## 使用

### 抓名单 + 导出

1. 进入「团员列表」。
2. 面板里点 **抓取名单**。日志第一行会打印 `分页：... 共 29 条，约 3 页`，然后是“已读取第 1/2/3 页”。
3. 表格每行最前面会出现一个红框方框，点它就是勾选；表格行变浅红。
4. 面板里点 **导出CSV**：有勾选就只导勾选的，没勾选就导全部。
5. 导出的文件用 Excel 直接打开，中文不乱码。

**如果自动翻页不成功**（日志停在“第 1 页”或提示“没有可用的下一页按钮”）：

改用手动兜底，30 秒搞定：

1. 你自己点页面上的 **下一页**；
2. 回到面板点 **追加本页**；
3. 重复两次（29 人共 3 页）。

这样得到的结果和自动抓取完全一样。

### 取重置码

两种方式，任选：

- **自动**：先在「名单」勾选人员 → 切到「取码」页 → 点 **为选中人员取码**。
  插件会翻到该人所在页、点它那一行的取码按钮、读弹窗、自动关掉、继续下一个。
- **手动**：你自己在页面上点钥匙图标。**只要弹窗一出现，插件就会自动记录**（这是兜底，不依赖按钮选择器）。

记录会出现在「取码」页，每条后面有「复制」按钮。

- **复制全部** / **导出码** 的格式都是 `姓名：验证码`（一行一个），可以直接发群里让团员认领。
- 导出的文件名是 `重置码_日期.txt`（UTF-8 带 BOM，记事本/Excel 打开都不乱码）。

> 日志不在取码页了：面板底部有一条 **日志** 栏，点「展开」看全过程，可复制、可清空，所有页签共用。

### 评议助手（两制）

进入「两制 → 团员教育评议」，右上角年度切到当前年度（如 2026），点面板的「评议」页签。

**1. 先把全支部读进来**

点 **读取全部**：插件先回到第 1 页，再一页页翻到底，把 29 人的姓名、年度、当前等次汇总到面板里。

- 分页是「首页 / 上一页 / 页码 / 下一页 / 末页」，读完会停在最后一页，正常情况下不用你管。
- 自动翻页失败时，用手动兜底：自己点页面「下一页」→ 面板点 **追加本页**。
- 读到的名单、勾选、清单存在当前标签页的 sessionStorage 里，**刷新也不丢**，关掉标签页即消失。

**2. 三步走：选 → 复查 → 应用**

> ⚠️ 应用会直接去点页面上的下拉。如果系统是“选中即保存”，点下去就改不回来；即使还要点「提交」，也不该靠事后补救。
> 所以插件绝不边勾边设，一切都先在面板里定好。

| 步骤 | 操作 | 会改网站吗 |
|---|---|---|
| ① 选 | 勾人 → 选等次 → **写入选中(N)**。等次只是写进面板里的「应用清单」 | **不会** |
| ② 复查 | 点 **复查并应用(k)**，它变成一页只读清单：谁、等次、在第几页、各等次人数、优秀占比 | **不会** |
| ③ 应用 | 在复查页点 **确认应用(k)**，再确认一次，插件才开始去页面上逐人点下拉 | 会 |

- 清单里如果写错了：点名字后面的 ✕ 单独移除，或「清空清单」重来。
- 页面上**已经评过**的人会被跳过（改不了），日志会写明。
- 应用时从第 1 页开始逐人选择，**一旦有一个人设失败就立刻停止**，日志告诉你成功几个、卡在谁身上、还剩几个没做。
- 优秀名额按 30% 算：29 人 → 8 人，超限会在应用前警告。

**3. 应用完自己复核、自己提交**

插件只负责把下拉点成你清单里的等次，**不会点「提交」**。做完请抽查两三个人，再在页面上点「提交」保存。

### 团员信息（表单批量填写）

进入「团员信息」页（地址含 `/manage/memberinfo`），面板点 **信息** 页签。这一个页面是**一个人的一份表单**（标签在左、控件在右的表格布局）：

1. **进入修改页就自动读模板**：不用先点按钮；它会扫出当前页所有字段，字段名取左边单元格的文字（如「手机号码」「民族」）。
   - **下拉选项的来源，按优先级**：① 录入页用的**系统字典接口**（`POST /v1/center/importenter`，带你的登录态，和系统自己用的是同一份数据）→ ② 页面组件里的选项 → ③ 内置兜底。
   - 字典对照（取自录入页源码）：`nationals`→民族、`edus`→学历、`politicals`→政治面貌、`youngStudents`→在读状况、`tzbPositions`→团内职务；职业是固定的两项：**青年学生 / 职业青年**。
   - 日志会写：`已取到系统字典：nationals、edus、politicals…` 和 `下拉选项：6/6 可用（系统字典 4 个，页面 0 个，其余用内置）`。
   - 真正应用时仍按页面上那一次展开的真实选项匹配，匹配不上会提示「下拉里找不到 X，请手动选」。
2. **进入修改态**：页面上是「修改 → 提交」两步的，先点这个按钮（等于替你点页面上的「修改」），字段才可编辑；只读标记随之消失。
3. 只在**要改的那几项**后面填新值，**留空的字段一律不动**。
   - ⚠️ **只有「职业 / 在读状况 / 学历」三个字段可改**；其余字段（姓名、身份证、民族、入团时间、手机号、政治面貌…）在面板里是**只读**的，插件也不会写。
4. 点 **复核并写入(n)**：先给你一张只读清单，逐条列出「字段 → 新值」，此时页面没变。
5. 在清单页点 **确认写入**：只把填了的字段写进表单（下拉按选项文字选中）。
6. **提交由你点**：核对无误后再点页面上的「提交」保存，插件绝不点提交。

- 日期控件比较挑，写完请到页面上瞄一眼是否被系统接受；不接受就手动改。
- **团干页已支持**：团内职务非空的人，点「编辑」后地址尾缀是 `cadresinfo`（不是 `memberinfo`）。插件把它和普通团员页当同一类处理，按字段名匹配，多出来的字段不会影响；面板会标「团干页」，批量复核页也会列出其中有几个团干。

**批量改同一批字段（多人）**

一人一份表单也可以一次改多个人，而且**不用在页面之间来回跳**：

1. 先在「名单」页点 **抓取名单**，勾选要改的几个人（例如 3 个）。
2. 到任意一个团员的信息页点一次 **读取本页表单** —— 这一步只是拿字段模板，模板会记住（刷新也不丢）。
3. 在「信息」页签把要改的字段填好（学历 = 初中 之类）。
4. 点 **批量应用(3人)** → 复核清单 → **试跑第 1 人** → 确认无误后 **开始批量(3)**。

配置本身可以**在名单页完成**：勾完人 → 切到「信息」页签 → 填值 → 批量应用，剩下的由插件自己跳转。

每个人会走：回列表 → 找到那行 → 点「编辑」（整页跳转）→ 点「修改」→ 填字段 → 点「提交」→ 等成功提示 → 点「返回」→ 下一个人。

注意：

- 批量**会由插件点「提交」**（不点就没法批量）；单人模式的提交仍归你点。
- 批量同样只写「职业 / 在读状况 / 学历」；其它字段即使混进清单也会被跳过并记日志。
- 每完成一个人，插件**先记账再点「返回」**——因为「返回」可能触发整页刷新，记账晚一步就会反复停在同一个人。
- 提交后 8 秒内没看到成功提示（或表单没变回只读），按“状态不明”停下，让你手动检查，不会硬着头皮往下跑。
- 逐人串行，任何一个人失败（找不到行 / 找不到「编辑」/ 没进表单 / 字段没写进去 / 没成功提示 / 没回到列表）立刻停止，日志写明已完成谁、卡在谁身上。
- 进度存当前标签页（sessionStorage），刷新可续跑，关掉标签页即中止。

### 录入预检
有两条路，任选；**推荐直接上传文件**，复制粘贴最容易串列、丢前导零。

**A. 上传表格文件（推荐）**

1. 点面板「录入」→ **选择表格文件**，选 `.xlsx` 或 `.csv`（老的 `.xls` 先在 Excel 里「另存为 .xlsx」）。
2. 插件自己解压解析（不联网、不调用任何外部服务），把表格填进下面的框并**立即预检**。
3. 表头需要包含：姓名、身份证、民族、入团时间、发展团员编号、手机号码（缺哪个就跳过哪项检查）。
4. `入团时间` 如果是真正的日期格式，插件会自动把 Excel 的天数换成 `2024-05` 这种写法。

**B. 复制粘贴**

在 Excel 里选中整块（**含表头**）复制 → 粘进框里 → 点「预检」。

**预检结果**

- 下方列出每一行的问题：身份证校验位、入团年龄、编号年份、手机号格式、重复行。
- 点「导出问题」得到 CSV，回 Excel 按行号改。
- 全部通过后再走系统原来的「选择文件 → 上传」。

> ⚠️ 身份证列请在 Excel 里设成**「文本」格式**：18 位数字按“数字”存，后几位会被压成 0，插件只能提示“疑似数字格式、可能失真”，救不回来。

### 设置

- 记录后自动关闭弹窗：默认开。
- 操作间隔：默认 400ms，建议不要低于 300ms。

## 已知限制

- **选择器依赖当前页面结构**。官方改版可能失效，表现为「抓取名单」失败或取码找不到按钮。
- 取码按钮如果识别不到，会退化为“你手动点、我自动记”，功能不受影响。
- 只支持 `zhtj.youth.cn`（全国版）。北京/广东/福建是另外三套系统，不支持。
- 面板固定在右侧，可能挡住页面右下角的小浮标；点标题栏的「—」可缩成圆形小按钮。

## 卸载 / 清数据

`chrome://extensions` → 移除即可。插件只存了一个设置项，没有缓存任何团员数据（关掉页面就没了）。

## 故障排查（v0.2）

### 面板完全不出现

按顺序查这四步：

1. **加载的文件夹对不对**：`chrome://extensions` 里点「加载已解压的扩展程序」时，选的必须是 **`F:\zhtj\extension`**（这个文件夹里能直接看到 `manifest.json`）。选成 `F:\zhtj` 会报“清单文件缺失”。
2. **开关是开的吗**：卡片右下角开关要是蓝色；卡片上若有红色「错误」按钮，点开把内容发我。
3. **改完要刷新两次**：在 `chrome://extensions` 点该扩展的刷新图标（⟳），再到团建页面按 `F5`。
4. **看控制台**：团建页面按 `F12` → Console，找 `[团务助手]`：
   - 有 `[团务助手] content script 已注入` → 脚本进来了，面板没渲染是渲染问题，把这行后面的报错发我。
   - 完全没有这行 → 脚本没注入：确认你用的是装扩展的那个浏览器（Chrome 装的扩展 Edge 不生效），且地址是 `https://zhtj.youth.cn/...`。

### v0.1 的已知 bug（已在 v0.2 修复）

v0.1 把“是否管理后台”判断成 `pathname.startsWith('/center')`，但真实地址是 `https://zhtj.youth.cn/zhtj/center/...`，pathname 以 `/zhtj/` 开头 → 永远不挂载。v0.2 改成 `includes('/center')`，并把匹配范围放宽到整个域名。

### 面板出来了但抓不到名单

- 确认在「团员管理 → 团员列表」页面（地址含 `manage/memberlist`）。

### 只抓到第一页（v0.3.1 继续加固）

v0.2.1 是靠“在整页里找分页控件”，容易抓到隔壁隐藏表格的分页器。
v0.3.1 改成：**从团员表格往上找最近的分页控件**，然后按「页码 2 → class 带 next → 文字下一页」依次尝试，并且**只有表格内容真的变了才算翻页成功**。

如果仍然失败，日志会写：

```
翻页失败：分页控件「...」，3 个候选都没反应。请手动点「下一页」后按【追加本页】。
```

这时就用手动兜底：点页面「下一页」→ 面板「追加本页」，两次凑齐 29 人。

## 团员增加 / 转出怎么办

名单是**快照**，不会常驻同步：

- 每次进「团员列表」点一次 **抓取名单**，就是最新的一份。
- 抓完会自动和上次比：日志里出 `相比2026/11/16：新增 2 人，减少 1 人`，或者 `与上次名单一致`。
- 比对用的是 **姓名+手机号**，不是序号——所以中间插人导致序号变化，也不会误判。
- 评议、注册页面每次都按系统当前名单读，新人自动包含。
- 建议：每学期开学抓一次，导一份 CSV 存档，期中和期末各抓一次看 diff。

注意：团员列表本身不显示身份证号，所以“导入预检”没法跟现有名单按身份证查重，只能查粘贴块内部重复。

## v0.3.4 改了什么

**1. 所有“读全部”都从第 1 页开始**

抓名单、读取评议名单之前，如果当前不在第 1 页，插件会先点「首页」回去（没有首页就一页页退），再往后一页页读，保证每次读到的都是完整的一份。

**2. 评议改成“选 → 复查 → 应用”三步，绝不边勾边设**

因为该系统是**选中即自动提交、提交后不可修改**，插件把所有选择都放在面板里完成：

- 勾人 + 选等次 → **写入选中**，只进面板的应用清单，**不碰网站**；
- **复查并应用** → 只读清单页：谁、什么等次、第几页、各等次人数、优秀占比；
- **确认应用** → 二次确认后才去点下拉，一人一次，失败立刻停并报出卡在谁身上。

面板同时加宽到 420px，清单能一眼看全；行内多出 `P2/P3`（在第几页）、等次徽标和 ✕（从清单移除）。

**3. 修掉“勾选一个人就弹回顶部”**

原因是每次勾选都把面板整块 HTML 重建了一遍，列表滚动位置被重置到 0（名单、评议两个列表都受影响）。现在勾选只改对应那一行的选中样式，不再重建；面板因为别的原因重绘时也会先记住再还原滚动位置。页面表格里的勾选框同样加了滚动保护。

**4. 翻页现在能前后走**

之前只认「下一页」，翻过去就回不来。现在分页器上的 **首页 / 上一页 / 下一页 / 末页** 都会用上，`取码`、`评议应用` 都能自己翻到目标页；只有这些按钮都点不动时，才会退回“刷新页面回第 1 页”的兜底。

**5. 下拉选择更稳**

点开下拉后改成轮询等它出现（不再死等 240ms），点完会回读输入框确认取值，不对就重试一次。评议“设了没生效”多半是这里。

**6. 录入支持直接上传表格**

「录入」页签多了 **选择表格文件**：直接选 `.xlsx` / `.csv`，插件自己解压读表（纯本地，不联网、不装依赖），自动认表头、把 Excel 的日期序列转成 `2024-05`，然后立刻预检。身份证若在 Excel 里是数字格式（后几位被压成 0），会单独提示“疑似数字格式、可能失真”。

**7. 新增「信息」页签：团员信息表单批量填写**


**8. 日志与取码分离**

- 日志从「取码」页搬到面板底部的独立抽屉（展开/复制/清空），所有页签共用，最多保留 300 条。
- 「取码」页只留码列表：每条可单独复制，支持 **导出码**（`重置码_日期.txt`），内容为 `姓名：验证码`。

## 检查更新

- 面板右上角出现「新版 vX.Y.Z」时，点它去下载。
- 「设置」页有 **检查更新** 按钮；插件也会每天自动查一次（不会上传任何数据）。
- 更新源是托管在 jsDelivr / Gitee / GitHub 上的 `version.json`；也可以在设置里填**自定义更新地址**。

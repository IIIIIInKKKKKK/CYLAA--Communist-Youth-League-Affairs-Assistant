> Microsoft Edge 加载项商店发布名称为 **团务助手 - 团员信息管理**。本工具为第三方辅助工具，与智慧团建官方平台不存在授权或隶属关系。

## 项目简介

**团务助手 · 智慧团建** 是一款面向共青团基层团务工作的辅助工具，旨在减少日常团务管理中的重复性操作，提高团务工作效率。

项目围绕智慧团建平台的常见工作场景，提供团员信息管理、数据导出、批量操作、教育评议辅助等功能。

本项目定位为辅助工具，不替代智慧团建官方平台，不改变团务工作的正式审批流程。

## 功能介绍

### 1. 团员信息管理

- 团员名单抓取。
- 分页数据读取。
- 团员名单 CSV 导出。
- 团员信息批量填写辅助。

### 2. 密码重置辅助

- 密码重置验证码记录。
- 相关记录整理。
- 数据导出。

### 3. 教育评议辅助

- 团员教育评议批量设置。
- 减少重复性人工操作。

### 4. 数据处理

- XLSX 文件读取与预检。
- CSV 文件读取与预检。
- 数据格式检查。
- 批量操作前的数据整理。

### 5. 操作管理

- 操作日志记录。
- 操作间隔控制。
- 版本更新检查。

> 批量评议与批量录入功能由使用者在工具面板中主动启动。批量录入任务启动后，工具会自动填写表单字段并点击页面「提交」按钮，操作前请务必核对目标人员与字段内容，并确认对相关数据拥有合法操作权限。

> 具体功能以实际发布版本为准，部分功能可能受到智慧团建平台页面调整、账号权限及浏览器环境影响。

## 安装与使用

### 第一步：获取软件

**方式一（推荐）：Microsoft Edge 加载项商店**

上架后可在 Microsoft Edge 加载项商店搜索「团务助手 - 团员信息管理」安装，后续更新也通过商店获取。当前商店版本审核中，请关注本项目 Releases 页面公告。

**方式二：开发模式本地加载**

前往本项目 GitHub 仓库 [团务助手](https://github.com/IIIIIInKKKKKK/CYLAA--Communist-Youth-League-Affairs-Assistant)，下载对应版本的源码压缩包。

### 第二步：安装

从商店安装：在 Edge 加载项商店页面点击「获取」即可。

本地加载：

- 先解压下载的压缩包；
- 在浏览器扩展管理页打开「开发者模式」，点击「加载解压缩的扩展」，选择解压所得的文件夹；
- **所选文件夹根目录下必须包含 `manifest.json`**，它是浏览器识别扩展的入口；`content.js` 与 `icons/` 目录需与其同级；
- 下载文件须来自本项目官方仓库，不要安装来源不明的修改版本。

### 第三步：使用

1. 使用具有相应权限的账号登录智慧团建平台。
2. 按照工具说明进入对应功能。
3. 根据实际业务需求选择操作。
4. 操作前核对相关数据。
5. 操作完成后检查平台中的实际结果。

具体操作步骤以对应版本的使用说明为准。

## 使用须知

1. 本项目仅用于合法、合规的团务管理辅助工作。
2. 使用者应确保拥有所操作数据及账号的合法访问权限。
3. 批量操作前，请认真核对目标对象和数据内容。
4. 对重要信息进行修改前，建议先做好必要的数据备份。
5. 请勿将真实团员信息、身份证号码、手机号、验证码及其他敏感信息上传至公开仓库。
6. 请勿将个人账号密码、访问令牌等敏感凭据提交到公开文件。
7. 请遵守智慧团建平台的使用规范及相关法律法规。
8. 请勿利用本工具实施未经授权的数据采集、修改或其他操作。

## 隐私与数据安全

本项目涉及团员名单、个人信息及相关业务数据，因此使用者应特别注意数据安全。

- 不要在公开渠道传播真实团员个人信息。
- 不要在 GitHub Issues、Pull Requests 或公开截图中提交敏感数据。
- 请妥善保管本地导出文件。
- 使用共享设备时，及时清理不再需要的敏感资料。

数据处理方式、网络通信范围、日志保存位置及数据留存期限，以公开的隐私政策为准。

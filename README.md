
# 团务助手 · 智慧团建

**基于 Chrome Extension Manifest V3 的智慧团建辅助工具。**

通过浏览器扩展，为团支部日常管理提供名单抓取、数据导出、验证码记录、团员评议、信息填写和数据预检等辅助功能。

**当前版本：v0.3.4**

## 功能介绍

### 1. 名单管理
- 自动抓取团员名单，支持分页读取。
- 支持人员勾选和 Shift 连选。
- 支持 CSV 导出。
- 支持与历史名单对比。

### 2. 重置密码验证码
- 自动记录页面弹窗中的验证码。
- 支持选中人员批量取码。
- 支持复制和 TXT 导出。

### 3. 团员教育评议
- 支持读取全支部评议名单。
- 支持批量选择评议等次。
- 提供「选择 → 复核 → 应用」流程。
- 支持操作日志和失败停止机制。

### 4. 团员信息填写
- 自动识别团员信息表单。
- 支持职业、在读状况、学历等字段填写。
- 支持单人操作和多人批量处理。
- 支持写入前复核。

### 5. 录入数据预检
- 支持 XLSX、CSV 文件。
- 检查身份证、入团年龄、发展团员编号、手机号及重复数据。
- 支持导出问题清单。
- 预检在本地完成。

### 6. 其他功能
- 操作日志记录。
- 自定义操作间隔。
- 版本更新检查。
- 支持 Chrome 和 Edge。

## 安装方法

1. 下载本项目 ZIP 压缩包并解压。
2. 打开 Chrome，访问 `chrome://extensions/`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择包含 `manifest.json` 的项目文件夹。
6. 打开智慧团建网站并登录使用。

Edge 用户访问 `edge://extensions/`，按照相同步骤安装。

团务助手 · 智慧团建

Chrome / Edge 浏览器扩展 · Manifest V3

一个面向智慧团建团支部管理场景的浏览器辅助工具，提供名单抓取、数据导出、重置密码验证码记录、团员教育评议辅助、团员信息填写和录入数据预检等功能。

通过页面辅助和批量处理，减少重复操作，提高日常团务管理效率。

功能概览

本工具目前提供六大功能模块。

1. 团员名单抓取与导出
自动读取团员列表，支持分页抓取。
汇总多页团员信息。
支持手动翻页后追加当前页数据。
支持逐行勾选团员。
支持 Shift 连续选择。
支持导出 CSV 文件。
有勾选人员时仅导出选中人员，否则导出全部人员。
支持与上次名单进行对比，识别新增和减少人员。
2. 重置密码验证码记录
自动识别重置密码验证码弹窗。
手动操作页面时，也可以自动记录弹窗中的验证码。
支持为选中人员依次执行取码操作。
支持逐条复制验证码。
支持复制全部验证码。
支持导出 TXT 文件。
导出格式为「姓名：验证码」，方便整理和核对。
3. 团员教育评议助手
自动读取整个支部的评议名单。
支持多页读取和手动追加。
支持按人员勾选。
支持设置评议等次。
支持生成应用清单。
支持应用前只读复核。
显示各等次人数及优秀比例。
应用过程中逐人处理，失败时停止并记录日志。

采用：

选 → 复核 → 确认应用

三步操作流程，避免勾选人员时直接修改网站数据。

4. 团员信息辅助填写
自动识别当前团员信息表单。
根据页面字段名称识别对应项目。
支持获取系统字典选项。
支持部分字段填写。
留空字段保持原样。
支持单人修改和批量填写。
支持写入前生成复核清单。
支持团员信息页和团干信息页。

目前可修改的字段限定为：

职业
在读状况
学历

其他字段在面板中保持只读，不纳入批量写入。

5. 录入数据预检

支持在本地对待导入表格进行预检查。

支持文件：

.xlsx
.csv

支持的检查项目：

身份证号码格式及校验位。
入团年龄。
发展团员编号年份。
手机号码格式。
重复数据。
Excel 身份证号码可能失真的情况。

支持导出问题清单，方便在 Excel 中修改。

预检不代替智慧团建系统原有的数据校验和正式导入流程。

6. 设置与更新
记录验证码后自动关闭弹窗。
设置页面操作间隔。
手动检查更新。
显示新版提示。
支持自定义更新地址。
支持多个更新资源来源。

使用教程
一、名单抓取与 CSV 导出

进入「团员管理 → 团员列表」。

打开团务助手面板。
点击「抓取名单」。
等待插件读取分页数据。
查看日志，确认读取页数和人员数量。
抓取完成后，可以在列表中逐行勾选人员。
点击「导出 CSV」。

导出规则：

已勾选人员：仅导出选中人员。
未勾选人员：导出全部人员。

支持 Shift 连选，方便批量选择。

自动翻页失败时的处理方式

如果日志提示无法找到下一页按钮：

自己点击智慧团建页面上的「下一页」。
回到团务助手面板。
点击「追加本页」。
重复操作，直到所有页面读取完成。

名单对比

每次重新抓取名单后，插件可以与上次保存的名单进行比较。

日志会显示新增、减少或名单一致等信息。

名单属于某次抓取时的快照，不代表实时同步。

二、重置密码验证码记录

进入「取码」页签。

提供两种方式。

方式 A：自动取码

在「名单」页勾选需要处理的人员。
切换到「取码」页。
点击「为选中人员取码」。
插件依次定位人员、打开对应弹窗并读取验证码。
完成后在面板中查看记录。

方式 B：手动取码

自己在智慧团建页面点击对应人员的重置密码按钮。
等待验证码弹窗出现。
插件识别弹窗并记录验证码。
在「取码」页查看记录。

验证码管理

支持：

单条复制。
复制全部。
导出验证码 TXT 文件。

导出格式：

text
张三：123456
李四：654321
王五：112233


文件名格式：

重置码_日期.txt

验证码属于敏感信息，请勿在公开场合传播或上传到公开仓库。

三、团员教育评议助手

进入智慧团建：

「两制 → 团员教育评议」

在页面中选择当前年度，再打开团务助手的「评议」页签。

第一步：读取全部名单

点击「读取全部」。

插件会尝试回到第一页，然后逐页读取评议名单。

如果自动翻页失败，可以使用手动方式：

自己点击页面上的「下一页」。
点击面板中的「追加本页」。
重复操作，直至读取完成。

第二步：选择评议等次

在面板中：

勾选需要设置的人员。
选择对应评议等次。
点击「写入选中」。
检查应用清单。

这一步只是在面板中建立应用清单，不会立即修改网站上的评议结果。

第三步：复核应用清单

点击「复查并应用」。

系统生成只读复核页面，展示：

人员姓名。
对应评议等次。
人员所在页码。
各等次人数。
优秀比例。

确认名单及等次正确后，再进入下一步。

第四步：确认应用

点击「确认应用」，按照提示再次确认。

插件才会开始逐人修改页面上的评议等次。

注意：

应用前必须核对人员及等次。
已经评过的人员可能被跳过。
如果出现设置失败，插件会停止后续操作。
应用完成后应自行抽查页面结果。
如果系统需要单独提交，应由授权人员按照页面流程完成最终提交。

优秀比例

当前版本按 30% 进行优秀名额提示和检查。

具体名额应以实际适用的管理规定及系统要求为准，不应仅依赖插件计算结果。

四、团员信息辅助填写

进入团员信息页面。

普通团员信息页面地址通常包含：

/manage/memberinfo

团干信息页面地址尾缀通常包含：

cadresinfo

打开团务助手的「信息」页签。

1. 读取表单

进入修改页面后，插件会尝试读取当前表单字段。

字段名称根据页面标签识别，例如：

手机号码
民族
学历
政治面貌
团内职务

下拉选项可能来自：

系统字典接口。
页面组件中的真实选项。
内置备用选项。

实际应用时仍需要以页面中的真实选项为准。

2. 进入修改状态

如果页面采用「修改 → 提交」的操作流程，需要先进入修改状态。

3. 填写需要修改的字段

目前仅支持：

职业
在读状况
学历

只填写确实需要修改的项目。

留空字段保持原样。

4. 复核并写入

点击「复核并写入」。

插件生成只读清单，展示准备修改的字段和新值。

确认无误后点击「确认写入」。

单人模式下，页面最终提交由用户自行完成。

日期字段可能受到系统格式限制，写入后应检查页面显示是否正确。

5. 多人批量填写

支持先在名单页选择人员，再配置需要批量填写的字段。

基本流程：

在「名单」页抓取人员名单。
勾选需要处理的人员。
进入一个团员信息页面。
点击「读取本页表单」，获取字段模板。
在「信息」页签设置需要修改的字段。
点击「批量应用」。
检查批量修改清单。
点击「试跑第 1 人」。
核对试跑结果。
确认后点击「开始批量」。

批量模式的处理流程：

返回团员列表。
定位目标人员。
进入编辑页面。
点击修改。
填写指定字段。
按批量模式执行页面提交。
等待系统成功提示。
返回列表。
继续下一位人员。

批量操作特别注意：

批量模式会在用户明确确认后自动点击页面上的提交按钮。

因此：

执行前必须核对人员名单和修改内容。
建议先试跑一人。
不要在没有核实结果的情况下重复执行。
如果提交后状态不明确，应先人工检查，不要直接重新批量提交。
遇到失败会停止后续任务并记录进度。

批量操作仅应由获得相应管理授权的人员执行。

五、录入数据预检

进入团务助手的「录入」页签。

提供两种方式。

方式 A：上传表格文件（推荐）

支持：

.xlsx
.csv

操作步骤：

点击「选择表格文件」。
选择准备导入的文件。
等待插件解析表格。
查看预检结果。
根据提示修改 Excel 中的问题。
再次进行预检。

表格建议包含以下字段：

字段	检查内容
姓名	基础信息
身份证	格式及校验位
民族	字段识别
入团时间	日期格式
发展团员编号	编号年份
手机号码	格式检查

缺少某些字段时，对应检查项目可能被跳过。

方式 B：复制粘贴

在 Excel 中选中完整数据区域。
包含表头一起复制。
粘贴到面板输入框。
点击「预检」。

预检结果

目前支持检查：

身份证号码校验位。
入团年龄。
发展团员编号年份。
手机号码格式。
重复行。
身份证号码可能存在的 Excel 数字格式失真。

发现问题后，可以点击「导出问题」生成 CSV 文件，按照行号返回 Excel 修改。

特别注意：身份证号码格式

建议在 Excel 中将身份证号码列设置为「文本」。

如果身份证号码以数字格式存储，Excel 可能导致末尾数字失真，插件无法恢复已经丢失的信息。

预检通过也不代表系统一定接受导入，正式导入前仍应使用智慧团建原有流程核对。

故障排查
1. 面板完全不出现

按顺序检查：

确认加载的是正确的扩展文件夹。
确认该文件夹内直接包含 manifest.json。
确认扩展处于启用状态。
在扩展管理页面检查是否存在错误提示。
点击扩展刷新按钮。
刷新智慧团建页面。

如果仍然没有出现：

打开页面开发者工具（F12），进入 Console，查找：

text
[团务助手]


如果有脚本注入日志但面板没有出现，请记录后续错误信息。

如果完全没有注入日志，请检查：

是否使用了安装扩展的同一个浏览器。
当前网址是否属于 https://zhtj.youth.cn/。
扩展是否启用。
Manifest 中的匹配规则是否正确。
2. 抓取名单失败

确认当前处于：

「团员管理 → 团员列表」

如果无法自动翻页：

手动点击页面下一页。
点击面板「追加本页」。
重复直至读取完成。
3. 只读取第一页

可能原因：

页面分页控件发生变化。
页面存在多个分页组件。
下一页按钮无法正常响应。
页面加载时间较长。

可以使用手动追加方式完成读取。

4. 重置验证码没有记录

检查：

是否真正出现了验证码弹窗。
当前页面是否为支持的系统页面。
是否有页面选择器变化。
是否存在脚本报错。

可以尝试手动打开验证码弹窗，再观察是否自动记录。

5. 下拉框填写失败

系统页面的下拉选项可能发生变化。

建议：

检查字段名称。
检查下拉选项是否存在。
手动确认真实选项。
不要在选项匹配失败时重复执行批量操作。
6. 批量操作中途停止

如果日志显示操作失败或状态不明确：

停止后续批量操作。
检查当前人员页面。
核实网站是否已经保存。
核对已经完成和未完成的人员。
确认状态后再决定是否继续。

不要在未确认实际提交状态时直接重复执行。

隐私与安全

本工具涉及团员管理信息，使用过程中应特别注意个人信息保护。

可能涉及的信息包括：

姓名。
手机号码。
身份证号码。
团员管理信息。
重置密码验证码。
其他个人资料。

请遵守以下原则：

仅在获得相应授权的管理场景中使用。
不要将真实团员名单上传至公开 GitHub 仓库。
不要将包含个人信息的 CSV、TXT、Excel 文件提交到 Git。
不要在 GitHub Issues 或公开讨论区发布身份证号码、手机号、验证码等信息。
导出的名单和验证码文件应妥善保存，使用完毕后及时清理。
不要分享登录 Cookie、账号密码、访问令牌等凭证。
执行批量修改前必须核对人员、字段和修改内容。
遇到系统提示、操作失败或状态不明确时，应停止并人工检查。

项目文档说明，录入预检主要在本地完成。其他功能的具体网络请求和数据流向，应以实际源代码为准。

本项目为第三方辅助工具，不代表智慧团建官方产品，也不应被理解为官方授权的软件。

使用者应自行确认其使用权限，并遵守相关平台规则、个人信息保护要求及适用法律法规。

找到「团务助手」。

Edge 用户：

打开 edge://extensions/。
找到「团务助手」。
点击「删除」。
